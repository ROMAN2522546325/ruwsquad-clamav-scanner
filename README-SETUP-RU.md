# Бесплатный ClamAV-сканер для RuWSquad

Этот отдельный репозиторий запускает ClamAV на GitHub-hosted Ubuntu runner и проверяет файлы из приватного Supabase Storage `ruwsquad-files`. JAR/ZIP не запускаются: сканер только читает содержимое и проверяет сигнатуры/вложенные архивы.

## 1. Создай репозиторий GitHub

1. Открой https://github.com/new.
2. Название: `ruwsquad-clamav-scanner`.
3. Выбери **Public**. Стандартные GitHub-hosted runners для публичных репозиториев доступны без оплаты в пределах правил GitHub Actions. Репозиторий содержит только код сканера, никаких ключей или загружаемых пользовательских файлов.
4. Загрузи в корень все файлы из этого архива, включая скрытую папку `.github/workflows`.
5. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret**.
6. Создай два секрета:
   - `SUPABASE_URL` — Project URL из Supabase → Project Settings → API.
   - `SUPABASE_SERVICE_ROLE_KEY` — секретный `service_role` key из Supabase → Project Settings → API Keys. Никогда не публикуй его и не помещай в HTML/JS.

## 2. Запусти сканер

1. Открой вкладку **Actions** своего репозитория.
2. Выбери **RuWSquad ClamAV scan**.
3. Нажми **Run workflow**.
4. Открой запущенный workflow и смотри лог каждого файла.

Автоматически workflow запускается раз в час. Каждая партия — до 6 файлов. Запуск повторно забирает зависшие задания, если предыдущая проверка оборвалась. Если файл помечен infected, он автоматически отклоняется; модератор может отдельно удалить исходный файл, обложку и скриншоты через панель. Если файлов больше, запусти workflow вручную ещё раз или дождись следующего часа.

## 3. Как трактуются результаты

- `clean` — ClamAV завершил проверку и не обнаружил известных сигнатур. Это не абсолютная гарантия безопасности.
- `infected` — обнаружена вредоносная сигнатура; запись автоматически переводится в `rejected`.
- `needs_review` — зашифрованный архив, превышение лимита, несовпадение SHA-256 или неполноценная проверка. Публиковать нельзя.
- `error` — сканер не смог закончить проверку; модератор может поставить повторное сканирование.

Публикация в RuWSquad разрешается только при `scan_status = clean`.

## 4. Важные ограничения

- ClamAV ищет известные сигнатуры вредоносного ПО. Он не гарантирует обнаружение всех стилеров, бэкдоров, обфусцированного кода или новых угроз.
- ClamAV **не определяет контент 18+ на изображениях**. Модератор должен просматривать обложку и все скриншоты в панели RuWSquad. Для автоматической NSFW-классификации нужен отдельный классификатор изображений и ручная проверка спорных результатов.
- Сканирование выполняется по расписанию, не синхронно во время загрузки. До результата статус остаётся `queued`, ресурс не публикуется и файл недоступен для скачивания.
- Публичный GitHub-репозиторий должен содержать только код. Не добавляй `.env`, service role key, реальные файлы плагинов или пользовательские загрузки.
- Не запускай JAR и содержимое архива как программы. Сканер этого не делает.
